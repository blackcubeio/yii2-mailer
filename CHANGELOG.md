Yii2 Mailer Change Log
======================


 * New: Multi-provider support (Mailjet, Postmark, SendGrid)
 * New: Namespace changed to `blackcube\mailer\{provider}\`
 * Upd: PHP 8.3+ required
 * Upd: Yii2 2.0.x required
 * Upd: Mailjet API v3.1 support
 * Upd: Codeception 5.x for testing
 * Fix: Replaced deprecated `each()` function for PHP 8+ compatibility
 * Enh: Modern PHP syntax (typed properties, union types, return types)
